✅ Next.js Advantages

  • Single deployment, single repository
  • Automatic Lambda scaling (100ms)
  • Better database connection pooling
  • Unified testing & debugging
  • Easier feature development
  • Native Amplify support
  • Fewer dependencies to manage
  • Simple microservice extraction path

⚠️ Express Concerns

  • Single 995-line server.js file
  • No built-in rate limiting
  • Manual scaling (2-3 minutes)
  • Connection pool management complex
  • Two separate deployments
  • CORS configuration manual
  • Unused dependencies (mongoose)
  • Harder to extract services
